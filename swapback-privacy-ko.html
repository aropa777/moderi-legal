Swapback 개인정보처리방침

시행일: 2026년 10월 7일 (이전 판: 2026년 8월 1일)

요약 — 개발자는 개인정보를 수집하지 않습니다. 서버·계정·분석·광고 SDK가 없습니다. 앱이 다루는 데이터는 이 Mac 안에 저장되고, 등록 목록만 본인 iCloud로 다른 Mac과 맞춰집니다.

1. 개발자가 수집하는 정보

없습니다. 앱은 이름, 이메일, 위치, 사용 기록, 기기 식별자 등 어떠한 개인정보도 개발자에게 보내지 않으며, 분석(analytics)·광고 SDK를 포함하지 않습니다. 회원 가입이나 로그인도 없습니다.

2. 이 Mac에만 저장되는 데이터

  • 설정: 등록한 슬롯(앱·폴더), 사이트 목록, 단축키, 환경설정
  • 클립보드 기록 (기본으로 켜져 있으며 설정에서 끌 수 있음): 복사한 글·그림·파일 경로, 복사할 때 앞에 있던 앱, 복사한 시각. 7일이 지난 항목과 300개를 넘는 항목은 오래된 것부터 정리됩니다. 비밀번호 관리자가 '숨김'으로 표시한 항목은 저장하지 않습니다. 이 표시가 없는 글(예: 메모에서 복사한 암호)은 저장되니, 원치 않으면 기록을 끄거나 지우세요. 기록을 꺼도 이미 저장된 기록은 설정의 '기록 전체 삭제'를 눌러야 지워집니다.
  • 스크린샷: 앱이 찍은 그림을 따로 보관하지 않습니다. 사용자가 복사하면 클립보드로, 저장하면 사용자가 고른 위치에 PNG로만 남습니다. (클립보드 기록이 켜져 있으면 복사한 그림도 위 기록에 포함됩니다.)
  • 사용 통계: 슬롯·사이트를 연 횟수와 시각 (설정에서 초기화할 수 있음)
  • 캐시: 사이트 아이콘, 사이트 검색 주소 목록

이 데이터는 개발자에게 보내지 않으며, 아래 4번에 적은 접속 외에는 제3자에게도 보내지 않습니다.

3. iCloud 동기화

iCloud에 로그인되어 있으면 등록한 슬롯(앱·폴더·파일 경로와 각 단축키)과 사이트 목록(주소·최근 사용 시각)이 Apple의 iCloud 키-값 저장소를 통해 사용자 본인의 iCloud 계정에 저장되어 다른 Mac과 맞춰집니다. 폴더·파일 경로에는 Mac 사용자 이름이 들어갈 수 있습니다. 개발자는 이 데이터에 접근할 수 없습니다. 환경설정·클립보드 기록·스크린샷·사용 통계는 올리지 않습니다.

4. 앱이 인터넷에 접속하는 경우

  • 사이트 아이콘: 아이콘을 보여 주기 위해 사용자가 등록한 사이트에 직접 접속해 아이콘 이미지를 받습니다. 제3자 아이콘 서비스를 쓰지 않습니다. 아이콘을 못 찾으면 상위 주소(예: google.com)에도 접속합니다. 일반적인 웹 접속처럼 해당 사이트는 접속한 IP 주소 등을 볼 수 있습니다.
  • 사이트 안 검색 주소 알아내기: 검색 주소를 모르는 사이트는 그 사이트의 첫 화면과 검색 안내 문서를 직접 받을 수 있습니다.
  • 사이트 검색 주소 목록: 하루에 한 번 GitHub Pages(aropa777.github.io)에서 공개 파일 하나(사이트별 검색 주소 목록)를 받습니다. 이때 사용자 정보는 보내지 않습니다. GitHub는 일반적인 웹 접속 기록(IP 주소 등)을 남길 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다.
  • 사이트 이동·사이트 안 검색: 사용자가 고른 사이트 주소와 입력한 검색어는 Safari에서 해당 사이트로 바로 열립니다. 사용자가 직접 웹을 이용하는 것과 같으며, 앱은 이를 저장하거나 개발자에게 보내지 않습니다.

5. macOS 권한

앱 전환과 ⌥ 화면은 아무 권한 없이 동작합니다. 아래 권한은 해당 기능을 처음 쓸 때만 묻고, 거절해도 앱 전환은 그대로 됩니다. macOS 시스템 설정에서 언제든 철회할 수 있습니다.

  • 화면 기록: 스크린샷 기능에서 고른 영역을 찍는 데에만 사용합니다.
  • 자동화(Safari 제어): 사이트 이동 기능에서 Safari의 탭을 전환하거나 여는 데에만 사용합니다. 열려 있는 탭의 주소는 기기 안에서 비교만 하고 저장하거나 전송하지 않습니다.

6. 결제

앱을 App Store에서 받거나 구매할 때의 결제는 Apple이 처리하며, 개발자는 결제 정보(카드번호 등)에 접근할 수 없습니다. 결제 관련 개인정보 처리는 Apple 개인정보처리방침을 따릅니다.

7. 데이터 지우기

클립보드 기록은 앱 설정의 '기록 전체 삭제'로 지울 수 있습니다. 앱을 휴지통으로 옮겨도 기록이 Mac에 남을 수 있으니, 앱을 지우기 전에 '기록 전체 삭제'를 눌러 주세요. iCloud에 맞춰 둔 목록은 macOS 시스템 설정의 iCloud에서 이 앱의 iCloud 사용을 끄거나 지울 수 있습니다.
